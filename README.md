# Sistema Web de Solicitud de Citas Médicas — Christus Muguerza

## Descripción

Este proyecto consiste en un prototipo web para la solicitud y gestión de citas médicas, desarrollado como parte de la materia Ingeniería de Software II. Está basado en los requerimientos y prototipos del proyecto realizado previamente en Ingeniería de Software I.

La aplicación está implementada en un único archivo HTML que integra HTML, CSS y JavaScript.

## Funcionalidades

- Inicio de sesión y registro de pacientes.
- Panel principal del paciente.
- Selección de especialidad médica, doctor, fecha y horario.
- Validación de los datos requeridos durante la solicitud.
- Consulta del estado de las citas.
- Panel del doctor para aprobar o rechazar solicitudes.
- Notificaciones dentro de la aplicación.
- Interfaz adaptable a computadoras, tabletas y teléfonos.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- LocalStorage del navegador para guardar los datos de demostración.
- Git y GitHub para el control de versiones y el alojamiento del código fuente.

## Cómo ejecutar el proyecto

1. Clonar el repositorio o descargar sus archivos.
2. Abrir el archivo `sistema_citas_christus_muguerza.html` con un navegador web actualizado.
3. Iniciar sesión con una de las cuentas de demostración o registrar un nuevo paciente.

### Cuentas de demostración

| Perfil | Correo electrónico | Contraseña |
|---|---|---|
| Paciente | `paciente@demo.com` | `demo123` |
| Doctor | `doctor@demo.com` | `demo123` |

## Alcance y limitaciones

Este proyecto es un prototipo académico, no un sistema oficial conectado a Christus Muguerza.

Los datos se almacenan localmente en el navegador. La aplicación no cuenta con un servidor ni una base de datos centralizada y no envía correos electrónicos reales. Por lo tanto, no debe utilizarse para gestionar citas médicas reales ni información clínica sensible.

## Propósito académico

El objetivo es aplicar conceptos de construcción de software, desarrollo de interfaces, validación de datos, organización de la lógica de la aplicación y control de versiones mediante Git y GitHub.
